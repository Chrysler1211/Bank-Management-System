# 📖 About the Project

This project is a simple **Bank Management System** developed in **Python** to strengthen my understanding of **Object-Oriented Programming (OOP)**.

The application allows users to:

- 🏦 Create bank accounts
- 💵 Deposit money
- 💸 Withdraw money
- 👤 View individual account information
- 📋 View all existing accounts

This project was built as part of my journey toward becoming a Software Engineer and Information Technology student.
